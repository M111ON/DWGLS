**TRAP (cost a wasted write — do not repeat):** the entry delimiter is
`ENTRY_DELIMITER = "\n§\n"` (`tools/memory_tool_store.py:25`). Joining entries
with `"§\n"` (or writing LF where the file had CRLF) makes the tool parse the

`replace` wipes everything. Always join with `"\n§\n"` and verify the tool
reports the expected `entry_count` right after writing.

### B. P3 route-log compaction — DONE (was the warm-path card's item 5)
The transition-only fix (2026-10-11, `b077552`) stopped **new** growth, but the
historical bulk stayed: the live log held **5,661 records for 7 distinct slots
(99% redundant)** and every boot replayed all of it.

New tooling (ann `c568921`):
- `scripts/p3_compact.py` — compacts **losslessly by construction**: replay is
  last-event-wins per `(name_hash, slot)` and CLEAR is the only reopen, so
  superseded records carry no information. `ANCHOR` (no state) and
  `CLEAR`-on-a-virgin-slot (a no-op) are dropped; kept records are copied
  **byte-exact** so CRCs stay valid. Dry-run by default; `--apply` writes a
  `.bak-<ts>` first; refuses on any CRC failure or if the replayed state would
  change.
- `tests/p3_compact_verify.c` — uses the REAL `wl_replay_log_file` the server
  runs at boot: `LATCH IDENTICAL: YES`.
- `tests/p3_append_test.c` — proves the compacted file still accepts appends
  (7 → 8 records, 0 old ids lost).
- `Makefile`: `p3-tools`, `p3-compact-dry`.

Measured then deployed:

| | before | after |
|---|---|---|
| records | 5661 | **7** |
| bytes | 181,155 | **227** |
| shut ids | 72,144,216,288,360,432,504 | identical |
| live `fog.replayed` | 5661 | **7** |

Edge cases 8/8 (repeat WRITE, WRITE+CLEAR, lone CLEAR, WRITE/CLEAR/WRITE,
ANCHOR-only, mixed slots, MOVE, foreign name_hash). Docs: `ann/WARM-PATH.md`
(commit `11d29af`).

**Why the live log stops growing on its own:** the anchor route walks ≤8 buckets
(`LZ_ANCH_MAXK=8`), and bucket 0 → latch id 0 = **reserved** (never written), so
only ids 72–504 can ever be logged — and they are now all shut. New queries
cannot add records. Compaction is still the right tool for other corpora where
more buckets get walked.
