### B. Real bug found: the warm path RAISED the budget
`lz_mem_search` set `budget = cov` (entries covered by the SHUT buckets) behind
the guard `cov < nent`. One bucket covers 24–30% of the index (B1 hard-bucket
wall), so a **repeat query scored 47027 vs the 24000 cold cap** on the
59756-row index — the warm path did *more* work than cold, the opposite of its
purpose.

**Why it was latent:** D5 made 24000 a hard cutoff on 2026-10-11;
`WARM-PATH.md` was written 2026-10-08 when the budget still auto-raised to N, so
`cov < nent` was trivially true and the bug never showed. Nothing re-ran the
warm path after D5.

**Fix** (`de73665`): gate the warm reorder on `cov < budget` instead of
`cov < nent`. When `cov >= budget` there is nothing to skip, so the cold walk is
kept untouched (reordering would only change *which* entries are scored, for no
speed win).

## 3. Honest caveats

- **The warm path is inert at the production default.** With 5 buckets covering
  >24000 entries (B1), `cov >= budget` always holds, so enabling
  `ANN_TOMBSTONE_WARM` changes nothing today. It only pays when the warm set is
  a genuine subset of the budget — i.e. when `LZ_ROUTE_BUCKETS` and/or the
  budget are tuned so the route covers less than the budget. The 2026-10-08
  numbers in WARM-PATH.md came from the buggy row and are annotated as such.
- **An exact repeat still does not reduce** (carried from the original doc): a
  repeat routes to the buckets the previous run just shut, so the SHUT set
  equals the walked set. The gain is on *overlapping* routes.
- **Warm is default OFF**; this session did not change the default. Turning it
  on is a product decision, and given the above it is currently a no-op.
- The C2 numbers are at `--budget 60000` (a deliberately loose budget) to make
  the warm set a genuine subset; they are a mechanism proof, not a live-traffic
  promise.
- The ANN fork is the live search core; `gguf_lazy_serve.c` in DWGLS is the
  model-serving binary and is **not** the live search path. Do not re-open the
  card against that file.
