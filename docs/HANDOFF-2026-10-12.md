## 3. Honest caveats

- **The A1/A4/A6 addresses are IDENTITY / placement keys, NOT a retrieval
  order.** Carried from A3 (memory #7581): the frustum ray key varies but is
  ~orthogonal to pattern-L1 nearest (nearest-shares-ray ~1%, mean in-bucket
  rank ~195). Do not wire these as a prune key.
- **The A6 hex address is coarse by construction** — the codec packs 14 bits
  (type 2b + xor-diff 4b + centre 8b), so its ceiling is ~4096 and the 52-letter
  alphabet saturates the centre byte (measured 1599 distinct over 5000). It is
  an address, not a hash.
- **The "anchor layer is DEAD" claim from the 2026-10-11 opencode session was
  a PROBE ARTIFACT** (a period-16 byte ramp aliases the 48-step rdh walk to
  zero; the A5 test's own comment records this). Re-verified this session:
  `aw_anchor_build` gives **64/64 seeds nonzero, 63/64 distinct** patterns.
  Do not re-open this as a real defect without a fresh, non-periodic probe.
- D5 query set = random index rows (same protocol throughout); the *shape* is
  right, the absolute number is a ceiling estimate, not a promise for live
  traffic.
- The fraction default (0.40) comes from 2 corpora at 300 queries; it is a
  floor-guarded heuristic, not a fitted constant. Tunable via env without
  rebuild.
