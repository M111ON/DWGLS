### Capo concept
- Like a guitar capo: shifts offset within source tensor while keeping 20736-slot cube structure.
- Cube 0 = index directory (capo_id → offset, length). 8 octants derived at runtime via mirror.
- Large tensor → N capos → each = 1 tesseract with its own cube 0 index.
- `tess_stride_scatter(i)` with `i = capo_offset + local_index` for addressing.

### Roundtrip verification
- 291/291 tensors bitwise identical after bake→assemble. token_embd (206 capos, 4.25M blocks) BITWISE IDENTICAL. output.weight (206 capos) BITWISE IDENTICAL.
- Assembled GGUF passes gguf_roundtrip (byte-identical, 675,710,816 bytes).
- Scatter throughput: 0.7-3 GB/s for typical cell sizes (Q8_0 = 144B). Bake speed: ~49 MB/s (I/O bound).
